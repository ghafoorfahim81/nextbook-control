# پیام‌ها به مشتریان: ایمیل و واتساپ

مرکز کنترل برای مشتریانی که اشتراکشان رو به پایان است، یادآوری می‌فرستد و در رویدادهای مهم (بلاک، رفع بلاک، دریافت پرداخت) اطلاع می‌دهد. هر پیام به زبان خود مشتری (دری، پشتو یا انگلیسی) است و تاریخ‌ها برای دری و پشتو جلالی با ارقام فارسی نوشته می‌شود.

## چه پیامی، چه وقت

| پیام | چه موقع |
|---|---|
| یادآوری ۳۰، ۱۴، ۷ و ۱ روزه | هر صبح ساعت ۸ به وقت کابل، برای اشتراکی که به آن آستانه رسیده |
| ختم اشتراک | یک‌بار، تا ۳ روز پس از پایان (بعد از آن کار آدم است، نه یادآوری) |
| بلاک / رفع بلاک | لحظه‌ای که کارمند بلاک می‌کند یا برمی‌دارد |
| دریافت پرداخت | لحظهٔ ثبت پرداخت، با مبلغ و شمارهٔ فاکتور |

- فقط مشتری «آزمایشی» یا «فعال». مشتری لغوشده، بایگانی‌شده یا بلاک‌شده یادآوری نمی‌گیرد.
- اگر یک روز اجرا نشد (مثلاً سرور خاموش بود)، اجرای بعدی همان آستانه‌ای را که از دست رفته **یک‌بار** می‌فرستد.
- هر پیام به «آنچه دربارهٔ آن است» بسته است (مشتری، نوع پیام، کانال، گیرنده و تاریخ پایان). پس اجرای دوباره در همان روز، **هیچ پیام تکراری** نمی‌فرستد، و بعد از تمدید، دورهٔ بعد یادآوری‌های خودش را دارد.

## چه کسی پیام می‌گیرد

در پروندهٔ مشتری، بخش «تماس‌ها»: پیام‌ها به **مدیر**، **مسئول مالی** و **تماس اصلی** می‌رود، فقط در کانال‌هایی که آن شخص پذیرفته (تیک «ایمیل فرستاده شود» / «پیام واتساپ فرستاده شود»). کسی که واتساپ را نپذیرفته، هرگز واتساپ نمی‌گیرد.

- شمارهٔ واتساپ هر شکلی باشد خوانده می‌شود: `0791234567`، `+93 79 123 4567`، `۰۷۹۱۲۳۴۵۶۷`. اگر خالی بود، شمارهٔ تلفن استفاده می‌شود. شمارهٔ نامعتبر رد می‌شود و در پرونده هشدار دارد.
- اگر مشتری هیچ تماسی با ایمیل یا شمارهٔ قابل‌استفاده نداشته باشد، «کسی برای نوشتن نیست» در بخش پیام‌ها دیده می‌شود (یک‌بار برای هر دوره)، تا کسی دنبالش برود.
- پیام ناموفق با دلیلش در همان بخش دیده می‌شود، با دکمهٔ «دوباره». تعداد پیام‌های ناموفق روی داشبورد هم هست.

## راه‌اندازی ایمیل

در `.env` سرور، تنظیمات SMTP لاراول:

```
MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=...
MAIL_PASSWORD=...
MAIL_FROM_ADDRESS=billing@yourcompany.com
MAIL_FROM_NAME="NextBook"
```

تا وقتی `MAIL_MAILER=log` است، ایمیل‌ها فقط در لاگ نوشته می‌شوند و هیچ‌جا نمی‌روند. ایمیل‌ها هم متن ساده دارند و هم HTML راست‌به‌چپ (برای دری و پشتو).

## راه‌اندازی واتساپ

واتساپ فقط از راه **WhatsApp Cloud API** رسمی Meta فرستاده می‌شود. نکتهٔ مهم: یک کسب‌وکار فقط می‌تواند با «قالب» (Template) تأییدشده‌ٔ Meta گفتگو را شروع کند؛ پس هر نوع پیام یک قالب لازم دارد، و متن قالب باید دقیقاً با متن پایین یکی باشد (بخش آخر).

1. یک حساب **Meta Business** و یک شمارهٔ **WhatsApp Business** بسازید.
2. در WhatsApp Manager، ۵ قالب پایین را بسازید. نام قالب باید همان باشد؛ **هر قالب برای هر زبان** (fa، ps، en) یک ترجمه دارد. دستهٔ پیشنهادی: *Utility*. تأیید Meta معمولاً از چند دقیقه تا چند روز طول می‌کشد.
3. یک **توکن دائمی** بسازید (System User در Business Settings با دسترسی `whatsapp_business_messaging`) و **Phone Number ID** شماره را بردارید.
4. در `.env`:

```
WHATSAPP_DRIVER=cloud
WHATSAPP_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
```

نام قالب‌ها پیش‌فرض‌های بالاست و با `WHATSAPP_TEMPLATE_EXPIRING`، `WHATSAPP_TEMPLATE_EXPIRED`، `WHATSAPP_TEMPLATE_BLOCKED`، `WHATSAPP_TEMPLATE_UNBLOCKED`، `WHATSAPP_TEMPLATE_PAYMENT` عوض می‌شود.

تا وقتی `WHATSAPP_DRIVER=log` است (پیش‌فرض)، پیام در لاگ نوشته و در صفحه «فرستاده‌شده» نشان داده می‌شود، اما **هیچ‌چیز نمی‌رود**؛ برای دیدن کل جریان پیش از داشتن حساب Meta.

اگر Meta خطا بدهد (شماره نامعتبر، قالب تأییدنشده، توکن منقضی)، همان دلیل Meta در بخش پیام‌ها نوشته می‌شود و پیام «ناموفق» می‌شود بدون تلاش بیهوده. فقط خطای موقت (قطعی شبکه، خطای سرور Meta) بعد از ۱ و ۵ دقیقه دوباره امتحان می‌شود.

## اجرا روی سرور

دو چیز باید همیشه روشن باشد:

```bash
# صف: پیام‌ها را می‌فرستد (با Supervisor یا systemd)
php artisan queue:work --tries=3

# زمان‌بند: هر دقیقه؛ یادآوری هر صبح ۸ کابل اجرا می‌شود (cron)
* * * * * cd /path/to/nextbook-control && php artisan schedule:run >> /dev/null 2>&1
```

بدون `queue:work` پیام‌ها نوشته می‌شوند ولی نمی‌روند («در انتظار»).

## آزمایش بدون ارسال

```bash
php artisan control:reminders --dry-run             # چه چیزی امروز لازم است
php artisan control:reminders --date=2026-11-10     # انگار آن روز است
php artisan control:reminders                       # اجرای واقعی (همان کاری که هر صبح می‌شود)
```

## متن قالب‌های واتساپ

متن‌ها از همان فایل‌هایی ساخته شده‌اند که برنامه استفاده می‌کند. `{{1}}`، `{{2}}`… مقدارها هستند و **ترتیبشان نباید عوض شود**.

### `nextbook_expiring`

مقادیر به‌ترتیب: `{{1}}` = customer، `{{2}}` = package، `{{3}}` = date، `{{4}}` = days

**دری (fa)**

```
سلام، {{1}}
اشتراک شما ({{2}}) در {{3}} ختم می‌شود ({{4}} روز مانده). برای تمدید با ما تماس بگیرید تا کارتان بدون وقفه ادامه یابد.
نکست‌بوک
```

**پشتو (ps)**

```
سلام، {{1}}
ستاسو ګډون ({{2}}) د {{3}} په ورځ پای ته رسېږي ({{4}} ورځې پاتې). د بې وقفې کار لپاره د نوي کولو په موخه له موږ سره اړیکه ونیسئ.
نکست‌بوک
```

**انگلیسی (en)**

```
Hello, {{1}}
Your subscription ({{2}}) ends on {{3}} ({{4}} days left). Contact us to renew so your work carries on without a break.
NextBook
```
